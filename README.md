# MLBB Skin Library

Website katalog komunitas untuk mengorganisasi informasi skin Mobile Legends.

## Fitur awal
- Tampilan dark mode, responsif, dan mobile-first.
- Kolom pencarian.
- Filter kategori skin.
- Area katalog yang siap diisi data terverifikasi.
- Struktur HTML, CSS, dan JavaScript tanpa framework.

## Menjalankan
Buka `index.html` melalui browser atau aktifkan GitHub Pages dari **Settings → Pages**, pilih branch `main` dan folder `/ (root)`.

## Catatan konten
Proyek ini independen dan tidak berafiliasi dengan Moonton. Gunakan hanya materi, gambar, dan file yang dibuat sendiri atau memiliki izin untuk dibagikan. Jangan unggah file yang melanggar hak cipta, mengubah gameplay, melewati proteksi, atau menghindari sistem anti-cheat.
